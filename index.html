用户使用说明书

安装、激活与各功能操作指南

📱 一、安装

  1. 下载最新版 APK 安装包（约 111MB）
  2. 手机设置 → 允许安装未知来源应用
  3. 点击安装包，按提示完成安装
安卓 8.0+ 需手动允许"安装未知应用"权限，安装完成后可关闭。

🔑 二、首次启动与激活

  1. 点击桌面图标"个人所得税"，启动页显示 2 秒
  2. 未激活状态自动弹出激活面板
  3. 复制管理员发给你的激活码，粘贴到输入框
  4. 点击"激活软件"，提示成功后自动进入首页
激活码与设备绑定。换手机或重装后，可用原激活码自助迁移到新设备。

🏠 三、首页

  • 搜索栏：输入关键词搜索功能/服务
  • 温馨提示：滚动公告栏，显示税务相关提醒
  • 年度汇算专题：点击"进入专题页"查看

📋 四、收入纳税明细查询

  1. 首页点击"收入纳税明细"进入
  2. 选择纳税年度（2019–2026）和所得类型
  3. 点击"查询"查看结果
  4. 顶部固定显示收入合计与已申报税额合计
  5. 长按收入卡片可修改、复制、删除

👤 五、我的页面

  • 未登录：灰色头像，点击"注册/登录"进入登录页
  • 已登录：显示姓名、纳税人识别号、家庭成员/任职受雇/银行卡数量
  • 任职受雇：长按企业卡片可修改、删除、复制
  • 个人信息：姓名、纳税人识别号长按可修改

🔐 六、申请授权（未激活时）

  1. 激活面板点击"查看价格并申请授权"
  2. 选择套餐时长与付款方式（支付宝红包 / 京东E卡）
  3. 按提示完成付款，填写付款凭证
  4. 填写接收激活码的邮箱，提交申请
  5. 管理员审核后将激活码发送至邮箱
工作时间 9:00–22:00，约 30 分钟内处理。

❓ 七、常见问题

Q：激活码输入提示错误？
检查是否复制完整、有无多余空格；确认套餐与激活码对应。
Q：换手机怎么办？
激活码与设备绑定。换手机或重装后，在激活面板用原激活码自助迁移即可。
Q：数据存在哪里？
所有数据存储在本地手机，不上传服务器。
