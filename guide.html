一、这是什么，不是什么

是什么：一款高保真复刻的个税 App 界面演示工具，可以查看收入纳税明细、维护个人信息与家庭成员、练习年度汇算相关操作，数据全部存在你手机本地。

不是什么：

  • 不是国家税务总局或任何税务机关的官方应用，与官方没有任何关联
  • 不能替代电子税务局等官方办税渠道，不能用于真实申报
  • 计算结果不构成纳税申报、汇算清缴、财务记账的依据

首次打开会强制阅读免责声明，同意后才能使用；不同意的请直接退出并卸载。

二、安装

  1. 从展示站或 GitHub Release 下载最新版 APK（geshui_v1.5.1.apk，约 111MB）
  2. 手机「设置 → 安全/应用管理」中允许当前文件管理器或浏览器「安装未知应用」
  3. 点击安装包，按提示完成安装
  4. 安装完成后可以把「安装未知应用」权限关回去

建议在 Wi‑Fi 下下载。安卓 8.0 及以上都需要手动授权「安装未知应用」，这是系统限制，不是应用本身要求。 只从本项目的展示站或 GitHub 仓库下载，二次打包的安装包可能被篡改。

三、首次启动：先过免责声明

第一次打开会出现整屏的免责声明卡片（深蓝底 + 白卡），包含 5 条要点：

序号 要点 意思
1 非官方工具 个人独立开发，与税务机关无关，不能替代官方渠道
2 结果仅供参考 算出来的数不作为申报依据
3 仅供个人学习 禁止转售、二次分发、公开传播，禁止用于虚假申报等违法用途
4 授权与设备绑定 激活码绑定本机，可在规定次数内自助迁移，请勿共享倒卖
5 付费与退款 费用是软件授权费，不含代办代缴；在线交付的数字化商品不适用七日无理由退货，请先试用再购买

卡片底部有「查看完整免责声明（12 节全文）→」，点击会在浏览器打开完整版；下方是「不同意，退出」和「同意并继续」。

  • 点「同意并继续」：记录同意版本，之后正常启动（以后版本更新若条款变化会重新弹一次）
  • 点「不同意，退出」：直接退出应用，不使用任何功能

四、启动后的三种状态

同意免责声明后，会看到约 2 秒的启动页（蓝色税盾图标），随后按你的授权状态分三种情况：

状态 表现 你要做什么
已激活且未过期 直接进入主界面 正常使用
未激活 / 已过期，但能领试用 进入主界面，顶部出现蓝色「🎁 免费试用中 mm:ss / 立即解锁」横幅 先用着，到期前决定是否购买
未激活且不能试用 停在激活面板 输入激活码，或点「查看价格并申请授权」

激活面板上能看到：当前状态（未激活 / 已激活 / 已过期）、到期时间、剩余天数、激活码输入框、「激活软件」按钮，以及这几个入口：

  • 「换机或重装？用原激活码迁移到本机」
  • 「没有激活码？点此查看价格并申请授权」
  • 「重新激活（清除当前激活码）」（已激活时才会出现，用于换一个新码）

系统公告会以卡片形式出现在激活面板和申请授权页，每天只提示一次，不会每次打开都挡住你。

五、免费试用

免费试用是给新用户先体验用的，是否开放、给多少时长，由管理员在后台配置（默认关闭）。开放时：

  1. 启动检测到本机没有有效授权，会自动为你领取一次试用（不需要点任何按钮）
  2. 进入主界面，顶部蓝色横幅显示剩余时间：🎁 免费试用中 09:57 / 立即解锁
  3. 点「立即解锁」会打开激活面板，可以边用边决定要不要买
  4. 试用到期，自动跳转到激活流程

断网时会怎样：横幅变成「试用已暂停」，并给出 15 秒宽限倒计时。

  • 这个倒计时是按真实时间走的，关掉面板再打开会接着往下数，不会重新从 15 秒开始（v1.5.1 已修复的问题）
  • 15 秒内恢复网络，试用继续；15 秒到点仍无网络，自动进入激活页
  • 试用期间必须保持在线校验，这是为了防止改系统时间来延长试用

试用次数：同一台设备由服务端记录，领过就不会无限重复领取；换设备后按新设备判断。

六、激活

6.1 拿到激活码

激活码是一长串字符，格式为 O|设备码|授权内容.签名，由管理员生成后发给你（邮箱或聊天工具）。

不要手动修改激活码中的任何字符，也不要加空格或换行，复制时整段粘贴。

6.2 输入激活

  1. 打开 App，停在激活面板
  2. 把激活码粘贴到「请输入激活码」输入框
  3. 点「激活软件」
  4. 提示「激活成功！到期时间：xxxx，剩余 xx 天」后自动进入主界面

永久授权会显示「永久有效」。

6.3 激活结果说明

提示 含义 怎么办
激活成功 + 到期时间 授权已写入本机 正常使用
该激活码已过期 码本身到期了 联系管理员续期或重新购买
该激活码已在其他设备上使用 码已绑在另一台设备 用迁移流程（见第八节），或申请新码
该授权已迁移到其他设备，本机授权已失效 你的码被别人迁走了 无需重新激活，联系管理员核实
激活码格式错误 复制不完整或多了字符 重新完整复制

七、设备码与绑定规则

设备码：激活面板/申请授权页会显示本机设备码，形如 and-1a2b3c4d5e6f7a8b，可以一键复制。

  • 设备码取自安卓系统的硬件标识，清除应用数据、卸载重装后仍然是同一个设备码
  • 只有恢复出厂设置或更换手机，设备码才会变
  • 激活码与设备码绑定：一个码在同一时间只服务一台设备

为什么要绑定：激活码是一次性授权凭证，绑定可以防止一个码被多人共用。

八、换机或重装：自助迁移

换新手机、或者恢复出厂设置后设备码变了，不用重新买，可以用原激活码把授权迁到新设备。

8.1 迁移三步

  1. 新设备：打开 App，在激活面板点「换机或重装？用原激活码迁移到本机」，粘贴原激活码，点迁移
  2. 原设备：保持 App 打开，会弹出「设备迁移请求」，显示申请设备的设备码前几位 - 是你本人操作 → 点「允许迁移」 - 不是你操作 → 点「拒绝」，授权保留在原设备
  3. 新设备：点允许后自动改绑，提示「迁移成功！到期时间：xxx（已迁移 1/2 次）」并进入主界面

原设备在允许之后立即失效，界面提示「授权已迁移到其他设备，本机已失效，无需重新激活」——这是正常的，不是让你再激活一次。

8.2 几个关键规则

情况 结果
新设备发起后，原设备一直没确认 24 小时后自动放行，并通知管理员；不会一直卡着
原设备点「拒绝」 迁移失败，授权仍在原设备
等待确认期间 新设备显示「⏳ 等待原设备确认」，可点「取消等待」重新发起
迁移次数 默认每个码最多 2 次（以后台配置为准），提示里会显示「已迁移 x/2 次」
次数用完 需要联系管理员重新处理
原设备已损坏/已卖掉，无法确认 等 24 小时自动放行，或直接联系管理员
只是重装、设备码没变 输入原激活码会直接激活成功，不走迁移流程

迁移是「改绑」不是「复制」：迁移成功后原设备就不能再用了。

九、续期与解绑

9.1 续期

到期前想继续用，不需要重新拿新码：

  1. 进入「我的 → 关于 & 更新」页
  2. 点「申请授权 / 续期」
  3. 页面会以「续期授权」模式打开，选择时长、付款方式、填凭证后提交
  4. 管理员确认后，到期时间自动延长，你下次打开 App 就会看到新的到期时间，不用重新输码

9.2 解绑

需要把某个码从某台设备上解绑（比如设备要转给别人、或者码要作废），联系管理员在后台操作即可。App 内没有自助解绑入口。

十二、收入纳税明细

12.1 查询

  1. 首页点「收入纳税明细」进入
  2. 选择纳税年度（默认 2019–2026）
  3. 勾选所得类型（工资薪金、劳务报酬、稿酬、特许权使用费等）
  4. 点「查询」

两个长按操作（页面上没有按钮，只能长按触发，按住约半秒松手）：

长按哪里 弹出的面板 怎么用
左侧「年度」两个字 设置年份范围 填起始年、结束年（4 位数字，默认 2019 ~ 2026），点「确定」；之后年份选择器只列这段区间里的年份。如果当前选中的年份落在新范围外，会自动收到边界年份
右侧的年份数字（如「2026」） 选择年份（2019~2026） 在列表里点选目标年份（选中项右侧打勾），点「确定」后生效；列表只显示上面设定的范围

两个面板都要点「确定」才生效，点「取消」或面板外的灰色区域即放弃。年份范围只在这次停留在本页期间有效，退出页面再进来会恢复为 2019–2026。

12.2 结果页

  • 顶部固定汇总卡：收入合计、已申报税额合计
  • 下方按月列出收入卡片，每张显示：所得项目小类、扣缴义务人、收入、已申报税额
  • 点卡片进入详情
  • 该年度没有记录时显示空状态：「点击或长按新增申报记录」，点一下就打开新增表单

12.3 新增、修改、复制、删除

  • 新增：空状态区域点击/长按，或结果页新增入口
  • 长按任意记录卡，弹出底部菜单：
  • 修改该条记录
  • 复制该条记录
  • 删除该条记录（二次确认）
  • 修改表单字段较多（收入、税额、扣缴义务人等），弹窗内可以上下滑动，最下面的字段也能滚到

金额都是演示数据，可以按你的需要随意改，不会影响真实税务记录。

十四、登录（演示规则）

登录页是演示用的，不校验真实身份：

  1. 「手机号码/证件号码」输入任意内容（如 13800000000）
  2. 「密码」输入任意内容
  3. 按住滑块拖到最右边，完成滑动验证
  4. 点「登录」即可进入

说明：

  • 任意账号密码都能登录成功，登录后以你输入的账号作为用户信息
  • 页面上还有「扫脸登录」「找回密码」等入口，属于界面还原，不实现真实功能
  • 登录状态保存在本地，重启 App 仍在；退出登录或新授权周期激活后会清空

十五、申请授权

15.1 入口

  • 激活面板：没有激活码？点此查看价格并申请授权
  • 关于页：申请授权 / 续期

15.2 申请流程

  1. 看价格表：套餐与时长以页面实时显示为准（价格由后台配置，可能随活动调整）
  2. 选付款方式：支付宝红包 / 京东 E 卡
  3. 按页面步骤付款： - 支付宝红包：在支付宝里发红包 → 生成「红包口令」（一串数字或汉字） - 京东 E 卡：买电子卡 → 在订单里拿到「卡号」和「密码」 - 支付宝红包单包上限 200 元，套餐金额较大时页面会要求你分几个红包，分别填写每个口令
  4. 填优惠码（选填）：有优惠码就填进去点校验，通过后按折后金额付款；切换套餐后优惠码会失效，需要重新校验
  5. 填付款凭证：按提示粘贴红包口令或卡密
  6. 填联系方式/邮箱：激活码会发到这里，务必填对
  7. 提交申请

15.3 提交之后

  • 管理员人工核对付款凭证，通过后生成激活码并发送到你填写的邮箱
  • 处理时间以页面公告为准（一般工作时间内较快，非工作时间会顺延）
  • 收到码后回到激活面板粘贴激活即可

付款前请先领试用确认功能符合预期。在线交付的数字化商品不适用七日无理由退货。

十八、数据存在哪、什么时候清空

18.1 存在哪

除激活校验和试用校验需要联网外，所有业务数据（收入明细、个人信息、家庭成员、银行卡、背景图、登录态）都保存在你手机本地，不上传服务器。

18.2 什么时候会清空

出现以下情况时，App 会清空上一轮的账号态和业务数据，让新周期从干净状态开始：

  • 首次激活成功
  • 换成另一个激活码激活成功
  • 迁移到新设备后在新设备激活成功

会被清掉：登录态、收入明细等业务数据、自定义首页背景图 会保留：设备码、免责声明同意记录、公告已读日期、当前授权状态

续期不清空：续期只是延长到期时间，你的数据都会保留。

18.3 卸载重装
